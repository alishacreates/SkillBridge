## Status Definitions

- **Planned:** Implementation not started.
- **In Progress:** Implementation underway.
- **Implemented:** Functionality exists but verification is incomplete.
- **Verified:** Acceptance criteria and tests have passed.
- **Blocked:** An external dependency or unresolved issue prevents progress.

## Traceability Policy

Each requirement must eventually reference:

1. Its source in the official problem statement or an approved supporting requirement.
2. Acceptance criteria.
3. Implementation files or modules.
4. Automated tests or other verification evidence.
5. Current status.

This initial matrix maps the SRS requirements to modules. It does not yet establish one-to-one traceability to every individual sentence of the official statement.

No requirement may be marked Verified solely because its UI exists.
